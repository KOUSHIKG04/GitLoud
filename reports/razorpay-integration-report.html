GitLoud Razorpay Payment Integration

Simple implementation report - June 3, 2026

Goal

The goal was to add payment support so users can upgrade to Pro. Pro unlocks paid features like private repository generation and custom AI API keys.

Why Razorpay

Stripe was removed because it is not the right option for the current India setup. Razorpay was integrated first because it provides test keys and can be switched to live keys later.

Payment Flow

User clicks Pro -> API creates Razorpay order -> Razorpay Checkout opens -> payment succeeds -> backend verifies signature -> user becomes PRO

Main Backend Changes

  • Added Razorpay dependency to the API app.
  • Added billing routes for status, order creation, payment verification, and webhook handling.
  • Mounted billing routes in the API app.
  • Verified Razorpay payment signatures on the backend.
  • Updated the user plan to PRO after successful verification.
  • Stored Razorpay order and payment ids for tracking.

Database Changes

  • Added billing provider field.
  • Added plan expiry field.
  • Added Razorpay order id field.
  • Added Razorpay payment id field.
  • Added billing provider enum with Razorpay support.

Frontend Changes

  • Added Pro pricing card on the landing page.
  • Added Razorpay checkout button through the billing action component.
  • Loaded Razorpay Checkout script in the browser only when needed.
  • Sent successful payment details back to the backend for verification.
  • Removed Stripe UI and code completely.

Environment Variables

  • RAZORPAY_KEY_ID - public key id from Razorpay dashboard.
  • RAZORPAY_KEY_SECRET - secret key used only on backend.
  • RAZORPAY_PRO_AMOUNT_INR_PAISE - Pro plan amount in paise.
  • RAZORPAY_CURRENCY - normally INR.
  • RAZORPAY_WEBHOOK_SECRET - optional for webhook verification.

Testing

Razorpay test mode was used first. In test mode, the same code path works like production, but no real money is charged. Later, live mode can be enabled by replacing test keys with live Razorpay keys.

Security Rules Followed

  • The Razorpay secret key stays only on the backend.
  • The frontend never decides the final paid status by itself.
  • The backend verifies the Razorpay signature before upgrading the user.
  • Payment ids are stored for debugging and support.

Final Result

Razorpay test checkout works. After payment verification, the user is upgraded to Pro and can use paid features such as private repository generation and custom AI API keys.
